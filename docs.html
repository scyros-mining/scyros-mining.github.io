Documentation

Installation

Scyros runs on macOS, Linux and Windows. The quickest way to install it is the installer script for your system.

macOS and Linux

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/fxpl/scyros/releases/latest/download/scyros-installer.sh | sh

Windows

In PowerShell:

powershell -ExecutionPolicy Bypass -c "irm https://github.com/fxpl/scyros/releases/latest/download/scyros-installer.ps1 | iex"

Cargo

Scyros is published on crates.io. This needs Rust 1.93 or newer. 

cargo install scyros

Nix

With flakes enabled:

nix profile install github:fxpl/scyros

Prebuilt binaries

Archives for macOS (Apple silicon and Intel), Linux (x86-64 and ARM64) and Windows (x86-64, also as an MSI installer) are on the releases page.

From source

git clone https://github.com/fxpl/scyros.git
cd scyros
cargo build --release

The binary is written to target/release/scyros.

First steps

List the subcommands, then ask any subcommand for all of its options:

scyros --help
scyros ids --help

The tutorial walks through a complete small study, from sampling to parsing.

GitHub tokens

Subcommands that call the GitHub API take a CSV file of personal access tokens with -t. The file has one column, named token, with one token per line: 

token
ghp_first_token
ghp_second_token

Never commit or share this file. Several tokens from the same account do not raise GitHub's limits. Please follow GitHub's rate limits and terms of service.

The pipeline

A study is a chain of subcommands. Each one reads a CSV file and writes one, so every intermediate result is a file that you can inspect, edit or share. The examples below form one chain, from sampling to parsing.

Sampling

scyros ids

Samples ids of public repositories uniformly at random, with replacement, from a seed you choose. Ids are fetched in batches of 100, one API request per batch, and an interrupted run resumes where it stopped. 

scyros ids -t tokens.csv -n 1000000 -s 42 -o ids.csv

scyros duplicate_ids

Sampling with replacement can draw the same repository twice. This removes rows that have the same id. 

scyros duplicate_ids -i ids.csv -o unique_ids.csv

scyros forks

Removes forks. A fork repeats the content of its parent repository, so keeping it would bias every later count. 

scyros forks -i unique_ids.csv -o repos.csv

Filtering

scyros metadata

Fetches each repository's metadata from the GitHub API, such as its language, size and dates. Responses can be cached, so running it again costs no API requests. 

scyros metadata -i repos.csv -t tokens.csv -c cache/ -o metadata.csv

scyros filter_metadata

Keeps repositories that pass limits on intrinsic properties: a minimum size in kB, a minimum age in days, and whether they contain any code. Stars and forks are not used. 

scyros filter_metadata -i metadata.csv -s 50 -a 60 --non-code -o filtered.csv

scyros languages

Fetches the full language breakdown of each repository and the SHA of its latest commit. The download step uses this SHA, which is what makes it reproducible. 

scyros languages -i filtered.csv -t tokens.csv -o languages.csv

scyros filter_languages

Keeps repositories that contain at least one language from a JSON list, and drops those that can no longer be reached. 

scyros filter_languages -i languages.csv -l languages.json -o selected.csv

Analysis

scyros download

Downloads each repository at its recorded commit and keeps the files whose extension matches a language in your keyword files. Files that contain none of your keywords can be discarded as well. It writes one log per project and one per kept file. 

scyros download -i selected.csv -t tokens.csv -k keywords.json -d repos/ -f files.csv

scyros duplicate_files

Removes duplicate files, using one of three criteria: identical bytes (exact), the same tokens in any order (bow), or a large share of tokens in common (overlap). 

scyros duplicate_files -i files.csv -s bow -o unique_files.csv

scyros parse

Parses each file with Tree-sitter and keeps the functions whose body contains at least one keyword, ignoring comments and string literals. For each function it records its size, its parameters, and the number and nesting depth of loops, conditionals and calls. 

scyros parse -i unique_files.csv -k keywords.json -o functions.csv

scyros pr

Collects the open, closed and merged pull requests of each repository, with their discussion and review comments. 

scyros pr -i selected.csv -t tokens.csv -o pull_requests.csv

Experimental

A twelfth subcommand, extract_benchmarks, extracts a function together with everything it needs to compile on its own. It produced the benchmarks of the floating-point study, but it is not yet included in the released binary.
